# Ranitas · Pedidos 🐸

App para armar pedidos familiares de **Gorditas Ranitas** (Torreón) sin drama: cada familia entra a la liga, pone a cada quien con sus gorditas (harina/maíz), chilaquiles, bebida y postre, y el anfitrión manda **un solo mensaje de WhatsApp** a la sucursal elegida, con resumen para cocina.

- Tablero tipo Kanban: **Armando → Pedido → Entregado → Historial**.
- Desde el historial se **repite** cualquier pedido anterior con un toque y solo se ajusta lo que cambie.
- Sincronizado en vivo entre todos los que abran la liga (Firebase Realtime Database).
- Un solo archivo: `index.html`. Publicado en GitHub Pages: https://ricardolopezreyero.github.io/pedidos/
